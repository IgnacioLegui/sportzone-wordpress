<h1>🏋️‍♂️ SportZone – WordPress Website</h1>
  <p>
    <strong>SportZone</strong> is an academic project developed as a
    <strong>sports web platform</strong>, created with <strong>WordPress</strong>
    and based on the <strong>Astra</strong> theme.
    The website aims to deliver a modern, clean, and responsive experience for
    presenting content related to sports, health, and wellness.
  </p>
  <hr>
  <h2>Live Demo</h2>
  <p>
    🔗 <a href="https://sport-zone.space" target="_blank">https://sport-zone.space</a>
  </p>
  <hr>
  <h2>Project Objective</h2>
  <p>
    The main goal was to build a functional, visually appealing, and easy-to-manage
    website for users without technical knowledge, leveraging the flexibility of
    the WordPress ecosystem.
  </p>
  <p>My focus included:</p>
  <ul>
    <li>Customizing the structure and design of the Astra theme.</li>
    <li>Adapting the color palette, typography, and visual style to match the project’s identity.</li>
    <li>Selecting and optimizing images and multimedia resources.</li>
    <li>Configuring navigation, sections, and content categories.</li>
  </ul>
  <hr>
  <h2>Technologies Used</h2>
  <ul>
    <li><strong>WordPress</strong> (CMS)</li>
    <li><strong>Astra Theme</strong> (visual and structural base)</li>
    <li><strong>Elementor</strong> and/or <strong>Native Blocks</strong> for visual composition</li>
    <li><strong>HTML5 / CSS3</strong> (custom adjustments)</li>
    <li><strong>Hostinger</strong> (web hosting)</li>
    <li><strong>PHP 8.x</strong> (WordPress runtime environment)</li>
    <li><strong>MySQL</strong> (database)</li>
  </ul>
